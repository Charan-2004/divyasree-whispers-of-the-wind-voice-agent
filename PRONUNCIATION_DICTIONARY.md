# Pronunciation Dictionary & Phonetic Normalization

To ensure natural, sophisticated pronunciation by Indian TTS models (such as Sarvam Bulbul v3), the AI agent applies phonetic mapping rules to critical real-estate terms, locations, currency notations, and brand names.

---

## 1. Core Brand & Geographic Phonetics

| Term | Phonetic Spoken Representation | Context & Notes |
| :--- | :--- | :--- |
| **Divyasree** | `Div-yaa-shree` or `Divya Shree` | Prevents robotic flat pronunciation; emphasizes gentle "shree". |
| **Nandi** | `Nun-dhee` or `Nandi` | Soft dental 'd' sound as native in Indian English/Kannada. |
| **Nandi Hills** | `Nun-dhee Hills` | Natural cadence for the scenic landmark. |
| **Devanahalli** | `Devana-halli` | Clear articulation of the airport corridor hub. |
| **Heggadihalli** | `Heggadi-halli` | Micro-location in Doddaballapura Taluk. |
| **Bengaluru** | `Bengaluru` or `Bangalore` | Natural Indian English pronunciation. |
| **Whispers of the Wind** | `Whispers of the Wind` | Always pronounce in full when introducing the project. |
| **WOW** | `Whispers of the Wind` | Never spell out W-O-W on voice calls; expand to full project name. |

## 2. Real Estate & Commercial Terminology

| Written Format | Phonetic Spoken String | Rule / Rationale |
| :--- | :--- | :--- |
| **₹92.4 lakh** | `92 point 4 lakh rupees` or `92.4 lakh` | Converts currency symbol to clear spoken words. |
| **₹2.46 Cr** | `2 point 46 crore rupees` or `2.46 crore` | Prevents abbreviation `Cr` from being spelled "C-R". |
| **1,200 sq.ft.** | `1,200 square feet` | Expands abbreviations to prevent "s-q-f-t". |
| **3,199 sq.ft.** | `3,199 square feet` | Expands abbreviation for clarity. |
| **20,000 sq.ft.** | `20,000 square foot` or `20,000 square feet` | Expands abbreviation. |
| **Dec 2029 / December 2029** | `December 2029` | Articulates target possession timeline clearly. |
| **HNI / CXO / NRI** | `H N I`, `C X O`, `N R I` | Clean letter spacing for acronyms if spoken. |
| **ROI** | `returns on investment` or `R O I` | Conversational clarity. |

## 3. Affirmation & Conversational Tokens

| Context | Recommended Spoken Phrase | Discouraged Repetitive Slang |
| :--- | :--- | :--- |
| **Lead states preference** | `"Understood."`, `"Got it."`, `"That makes sense."` | Repeating "Absolutely" or "Awesome" every turn. |
| **Lead confirms budget fit** | `"That's helpful."`, `"Perfect, that fits comfortably."` | "Great, you can afford it!" |
| **Lead shares multi-part info** | `"That is very clear, thank you."` | Re-asking each item individually. |
| **Lead is busy / not now** | `"I completely understand. When would be a better time to reconnect?"` | Continuing the pitch aggressively. |
| **Lead wants callback** | `"Certainly. I will have our Property Expert reach out to you."` | "Okay bye." |
