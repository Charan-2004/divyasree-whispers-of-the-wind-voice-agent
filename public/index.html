About this Demo

Whispers of the Wind is a browser-based AI voice-agent demonstration built to showcase the complete conversational experience without requiring paid telephony infrastructure.

Why browser-based?

For this assignment, I chose a browser-based outbound-call simulation rather than PSTN/telephony infrastructure. This keeps the demonstration focused on the AI voice-agent experience while avoiding unnecessary telephony costs.

Demo Availability & API Quotas

This demonstration relies on external AI APIs and their available quotas. If the voice agent is temporarily unavailable, slow, or unable to respond, the most likely cause may be temporary API availability or exhausted development/demo credits rather than an issue with the interface itself. The repository contains the complete implementation and setup instructions for running the system independently.
